# Portfólio Digital — organização da entrega final

Este diretório está preparado para receber os artefatos acadêmicos oficiais da entrega final do Sistema de Gestão Artesanal.

Arquivos que **não foram fornecidos não são criados artificialmente**. A estrutura e a nomenclatura esperadas são:

```text
docs/
├── Documentacao_Final_ABNT.pdf
├── Documentacao_Final_ABNT.docx
├── Manual_do_Usuario.pdf
├── Manual_Tecnico.pdf
├── Relatorio_Implantacao_Treinamento.pdf
├── Termo_de_Entrega_e_Recebimento.pdf
├── sprints/
│   ├── Sprint_0_Backlog.pdf
│   ├── Sprint_1.pdf
│   └── Sprint_3.pdf
├── apresentacao/
│   ├── Apresentacao_Final.pptx
│   └── Apresentacao_Final.pdf
└── evidencias/
    ├── README.md
    └── links-videos.md
```

## Documentos técnicos já existentes no repositório

- `ATUALIZACAO_FUNCIONAL_2026-09-16.md` — registro das melhorias funcionais implementadas.
- `ARQUITETURA_FINAL.md` — arquitetura realmente utilizada pela aplicação.
- `RELATORIO_LIMPEZA_FINAL.md` — limpeza, estabilização, validações e limitações da versão final.

## Regra de organização

Somente documentos acadêmicos reais e aprovados pela equipe devem ser adicionados, seguindo a estrutura definida acima.
